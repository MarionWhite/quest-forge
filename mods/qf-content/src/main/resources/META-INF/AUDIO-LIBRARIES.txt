Audio libraries bundled in this mod
===================================

The jukebox reads mp3 and Ogg Vorbis through javax.sound.sampled, which Java 8
does not support on its own. The decoders below are bundled inside this jar,
UNMODIFIED, and are used through their public interfaces only -- they register
themselves as service providers and are never subclassed or patched.

Replacing a bundled library
---------------------------

The LGPL reserves the right to run this mod against a modified version of any of
these libraries. To do so, put your build of it earlier on the classpath than
this jar -- as a coremod library, or through the launcher's classpath options --
and Java will load yours in place of the copy bundled here. Nothing in this mod
refers to these classes by name; they are reached only through the service
provider files in META-INF/services, so an equivalent replacement will be picked
up with no changes to this mod.
