# The configs the pack fingerprint covers, relative to config/.
#
# Read by qf-content (PackFingerprint) on both the server and the client, and by
# tools/pack_fingerprint.py, which computes the same fingerprint from pack/config.
# Only the ID-bearing ENTRIES of each file count (integer values whose key has an
# id token or names a potion/biome/enchant/dimension/villager/profession/provider,
# or that sit in a section that does), outside any section with "client" in its
# name. Comments, layout, line endings, key order and every other setting are
# ignored, so a friend's edited keybinding or a reflowed file never refuses anyone.
#
# Built by scanning pack/config: `py -3.10 tools/pack_fingerprint.py --scan` lists
# every config with ID entries that is neither here nor reviewed-out below, and
# exits 1 if there is one. Add a file here when a mod that assigns IDs joins the pack.
#
# Changing this list changes every fingerprint, and it ships inside the qf-content
# jar, so client and server always use the same list.
