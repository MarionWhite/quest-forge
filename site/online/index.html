How to get on

  1. Install the pack from the release, not from a mod list. The server lets in only the exact release it was built from.
  2. Sign in with a real account. The server runs in online mode, so Prism Launcher with your Microsoft account; the release's own offline launchers are refused.
  3. Ask the host to whitelist your exact Minecraft name. The whitelist stores the account behind the name, so a typo means "You are not white-listed".
  4. Add the address under Multiplayer and expect the first join to take a few minutes.

If the server disconnects you with a message about your pack, the install page says what each one means.

Status is read through api.mcstatus.io, which pings the server the same way the in-game server list does. Names are shown only while a player is on; nothing here keeps a history.
