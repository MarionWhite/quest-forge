# Credits: round 0 reference images

The `ref-*.jpg` files in this folder are real-world reference images from Wikimedia Commons, shown
next to our renders so a calibration choice doesn't depend on how well an early shader draws it.
Each is a web-sized copy (at most 1600 px wide) of the original, otherwise unmodified. Every one is
public domain or under a Creative Commons licence that allows reuse with credit; the page shows
the credit and a link under each image. Files under CC BY-SA keep that licence.

All other images here (`<scene>-<option>.jpg`) are our own in-game renders.
