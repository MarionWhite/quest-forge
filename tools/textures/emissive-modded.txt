# Modded block textures whose bright pixels emit light (LabPBR _s alpha), read by
# tools/shaders/gen_surface_pack.py --emissive (the default) and by build_modded_textures.py.
# One texture per line as <domain>/<name> (inside assets/<domain>/textures/blocks/). Names the
# classifier already calls emissive (lamp, lantern, glowstone, glow, torch, candle, brazier,
# _on, lit) need not be here but may be. Every name was checked against the jars' listings
# (docs/design/textures/modded-blocks.md, section 4b); a missing one is reported at build time.
# Which pixels emit is decided by brightness (luminance above 0.45), so a lamp's frame stays dark.
