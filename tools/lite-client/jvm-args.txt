Quest Forge LITE -- Java settings (Java 8 only)
==============================================

Prism Launcher: Edit instance -> Settings -> Java.
Tick "Memory" and "Java arguments", then fill them in from the table below.

How much RAM does this PC have?
  Windows: Settings -> System -> About -> "Installed RAM".

  Installed RAM   Minimum memory   Maximum memory
  8 GB            1024 MiB         3072 MiB
  12 GB           1024 MiB         4096 MiB
  16 GB           2048 MiB         5120 MiB
  32 GB or more   2048 MiB         6144 MiB

Do NOT give the game more than that. On 8 GB the game is not the only thing
that needs memory: Windows takes 2.5-3 GB, Discord and a browser another 1-2,
and with integrated graphics the "video memory" also comes out of the same
8 GB. Past about 3 GB of heap an 8 GB PC starts swapping, which stutters far
worse than a smaller heap ever does.

Java arguments (paste ALL of this as one line):

-XX:+UseG1GC -XX:MaxGCPauseMillis=50 -XX:G1HeapRegionSize=16M -XX:+ParallelRefProcEnabled -XX:+DisableExplicitGC -XX:+UseCompressedOops -XX:MaxPermSize=256M -XX:+UseSplitVerifier -XX:+FailOverToOldVerifier -XX:-HeapDumpOnOutOfMemoryError -Djava.net.preferIPv4Stack=true -Dfml.ignoreInvalidMinecraftCertificates=true -Dfml.ignorePatchDiscrepancies=true -Dlog4j2.formatMsgNoLookups=true

Notes:
  * The two -Dfml.ignore* flags are REQUIRED: the pack's Forge jar is patched
    (the loading screen and its music live in it) and will not load without them.
  * MaxPermSize is ignored by Java 8 (it prints a warning) but is harmless; it is
    kept so the same line works on the pack's other launch scripts.
  * No ParallelGCThreads / ConcGCThreads here on purpose: Java picks them from
    the CPU, which is right for a 4-8 core PC. The pack's own launcher pins 6
    because that PC has 24 threads.
  * Java must be 1.8 (Java 8), 64-bit. Not 11, 17, 21 or 25. The pack is tested
    on 8u241. A 32-bit Java cannot give the game more than about 1.5 GB and will
    crash during loading.
