# Client-only jars the LITE / POTATO profiles move out of mods\.
#
# Every jar here is on the CLIENT_ONLY list in tools/server/build_play_server.py:
# the friends' server does not have it, so a client without it joins exactly as
# a client with it does, and no block, item, mob, recipe or quest changes.
# Never add a jar that is not on that list. A client missing any mod the server
# has is refused at login.
#
# OptiFine is client-only too, but it is the main performance mod: it stays.
# Columns: tier <TAB> jar-name prefix <TAB> what you lose / why it costs.

lite	SoundFilters	reverb and muffling. Ray-traces block occlusion for each sound it plays; a mob fight plays dozens at once.
lite	MobDismemberment	gore: severed limbs fall off killed mobs as extra physics entities.
lite	MobAmputation	gore: the same for player-like mobs.
lite	CustomMenu	the branded title screen buttons. Title screen only. The splash and menu music stay (they live in the Forge jar).
potato	journeymap	the minimap and full map. Its mapping threads re-render map tiles as chunks change, competing with the game for 4 cores.
potato	DamageIndicators	the mob health bar and portrait (draws the targeted mob a second time every frame) and damage numbers.

# Kept even in POTATO: InventoryTweaks and Controlling (no measurable cost; sorting and keybind search).
