# Pack definition

What makes Quest Forge a pack rather than a folder of mods. This is the content
that would be shipped to a player alongside the mod jars.

| Path | Contents |
|---|---|
| `config/` | Every mod's configuration, as tuned for this pack. 900+ files. |
| `scripts/` | CraftTweaker scripts: recipe gating, ProjectE defaults, in-game tips. |
| `resourcepack/` | The branding resourcepack the game actually loads — wordmark, menu background, Better Questing theme, icons. |
| `reports/` | Generated measurements. Not hand-edited. |
| `mods.tsv` | The manifest: every third-party mod file the pack loads, with name, version, category and size. |

## `mods.tsv`

111 rows, tab-separated, sorted by category then name. This is the authoritative
record of what the pack contains, since the jars themselves are not committed.

```
file    name    version category        bytes
```

The same data, written for people rather than scripts, is at
[`../site/modlist/`](../site/modlist/).

The pack loads **111 mod files** but Forge reports **141 registered mods**. Both
numbers are correct: several jars register more than one mod — the Legends Mod
alone contains five, and a number of mods register an API alongside themselves.

## `config/`

Committed in full, because config *is* the pack — two installs with the same jars
and different configs are different packs.

Excluded from it: `*.bak-*` snapshots (six were deleted when this repository was
assembled — git replaces them), and the runtime dumps the content mod writes into
`config/`, which were moved to `reports/` since they are output, not settings.

## `reports/`

Generated by the in-game `/qfcensus` and ore-survey commands, and by the merge
scripts in [`../tools/survey/`](../tools/survey/). Fixed-width `.txt` because the
columns are meant to line up.

| File | What it measures |
|---|---|
| `qfcontent-enchantments.txt` | The full 256-slot enchantment registry as loaded. The only reliable source for which IDs are free. |
| `qfcontent-oresurvey.txt` | Ore counts per dimension. |
| `qfcontent-oreveins.txt` | Vein clustering, derived from the survey. |
| `ore-vein-parameters.txt` | Vein rate, size and depth per ore, per dimension. |
| `ore-vein-parameters-without-hbm.txt` | The same survey with HBM's ore mod removed. Kept as a matched pair: adding or removing an ore mod requires a full re-survey, not filtering the existing one — the A/B is the proof. |
