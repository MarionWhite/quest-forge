# the Faithful 32x modern Java texture that draws the same block. Read by
# tools/textures/build_modded_textures.py, which takes the pair only when the mod's 16x texture
# and Faithful's 32x one agree in colour (mean colour distance and a pixel-wise comparison at 16x,
# thresholds in the script); the rest are reported as [guess] and left out of the build.
# Format: <domain>/<name> = <modern block texture name under assets/minecraft/textures/block/>
# Faithful 32x Java 1.21.1 (june-2026-release), Faithful License v4; recorded in the doc.
